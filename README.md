# Internet speed test (Node.js)

Консольный скрипт: делает 10 последовательных запросов к указанному адресу, дожидается полного ответа на каждый и выводит среднее время запроса, общий объём скачанных данных и скорость скачивания.

## Требования

Node.js 18+ (используется встроенный `fetch`). Зависимостей нет, `npm install` не нужен.

## Запуск

```bash
node speedtest.js <url>
```

Например:

```bash
node speedtest.js https://proof.ovh.net/files/10Mb.dat
```

Пример вывода:

```
# 9  10.49 MB  167 ms
#10  10.49 MB  162 ms

--- Result ---
Successful:   10/10
Average time: 398 ms
Downloaded:   104.86 MB
Speed:        210.84 Mbit/s (26.36 MB/s)
```

## Единицы

- Время запроса: миллисекунды (ms).
- Объём: мегабайты, 1 MB = 1 000 000 байт.
- Скорость: мегабиты в секунду (Mbit/s), как её указывают провайдеры; в скобках то же в мегабайтах в секунду (MB/s).

## Как считается

- Время запроса: от отправки запроса до получения последнего байта тела ответа.
- Скорость: общий объём / суммарное время всех успешных запросов.
- Запросы идут с `Accept-Encoding: identity`, чтобы сервер не сжимал ответ и считался реальный объём, прошедший по сети.
- `cache: no-store`, чтобы каждый запрос реально ходил в сеть.

## Ошибки

- Неверный адрес: скрипт печатает подсказку по использованию и завершается с кодом 1.
- Неудачный запрос (HTTP-ошибка, сеть, таймаут 120 с) выводится в консоль и не учитывается в итоге.
- Если не удался ни один запрос, скрипт завершается с кодом 1.
